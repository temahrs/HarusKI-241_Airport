## Можливості застосунку
База даних у Docker: Середовище PostgreSQL у Docker-контейнері (`docker-compose`).
Автоматична ініціалізація: При першому запуску програма самостійно створює схему та заповнює початкові тестові дані.
Розділення прав доступу:
`ROLE_USER` — перегляд списку міст, аеропортів та рейсів.
`ROLE_ADMIN` — повний доступ: додавання та каскадне видалення записів.
Вимоги "Відмінно»":
Паролі користувачів у БД закодовані в Base64.
Параметри підключення передаються через конфігураційний файл `application.properties`.
